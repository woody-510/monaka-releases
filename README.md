# monaka（試作）

どのWebページにも、流れるコメントを重ねて表示するブラウザ（Windows）と Chrome の拡張機能です。
ここは配布用の置き場です（プログラムのソースは置いていません）。

## ダウンロード

[最新版のページ](https://github.com/woody-510/monaka-releases/releases/latest) から `monaka-<版>.zip` をダウンロードして展開し、中の `Install-Guide.pdf` を見てください。

- `monaka-<版>.zip` … はじめて入れる人用（アプリのインストーラー・Chrome の拡張機能・入れ方の PDF）
- `monaka-Setup-<版>.exe` … アプリのインストーラーだけ
- `latest.json` … アプリが新しい版を見つけるためのファイル（ダウンロードしなくて大丈夫です）

## もう入れている人

アプリは、新しい版が出るとトップページに「今すぐ更新する」が出ます。押すだけで新しい版になります（0.1.1 から）。
Chrome の拡張機能は、ZIP の中の `ChromeExtension` フォルダで入れ替えてください。

## 注意

- 試作版です。インストーラーに署名がないので、開くと「Windows によって PC が保護されました」と出ます（「詳細情報」→「実行」）。
- 送信ボタンの横が「みんな」のとき、書いたコメントは monaka を入れている人みんなに見えます。個人情報は書かないでください。
